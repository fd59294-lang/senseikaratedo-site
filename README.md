# Site du club Sensei Karaté Do (Haussy, Nord)

Site statique publié sur Cloudflare Pages, domaine senseikaratedo.fr.

- `index.html` : la page du site
- `contenu.js` : tout le contenu évolutif (ceinture du mois, mots du dojo, kihon, katas, nunchaku)
- `hymne.mp3` : l'hymne du club

Pour ajouter une fiche, modifier uniquement `contenu.js`.
